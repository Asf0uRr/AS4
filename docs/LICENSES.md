# Licences

This is a practical summary, **not legal advice**. Verify the licence file of the exact release you bundle.

| Component | Licence | Redistribution on your USB |
|---|---|---|
| AS4 IR Tool scripts (`app\`, `scripts\`, launchers) | Created for the analyst; no third-party code included | Yours to decide |
| Hayabusa (Yamato Security) - bundled | AGPL-3.0 for the program; rules under the Detection Rule License 1.1 | Keep licence texts; offer source (https://github.com/Yamato-Security/hayabusa) |
| Chainsaw (WithSecure Labs) - bundled | GNU GPL v3 (`tools\Chainsaw\chainsaw\LICENCE`) | Allowed under GPL-3.0: keep the licence text, and offer source (https://github.com/WithSecureLabs/chainsaw) |
| Sigma rules (bundled inside Chainsaw archive) | Detection Rule License (DRL) - see `tools\Chainsaw\chainsaw\sigma\LICENSE` | Keep attribution |
| KAPE (Kroll) | Proprietary; free for personal/internal use, not redistributable | **Do not bundle for others**; each analyst downloads it |
| FTK Imager (Exterro) | Proprietary freeware | Check Exterro terms before copying to shared media |
| WinPmem (Velocidex) - bundled | Apache-2.0 | Allowed with the licence |
| Volatility 3 - bundled (`LICENSE.txt` in its folder) | Volatility Software License | Read the VSL before copying to others |
| Sysinternals tools - bundled | Microsoft Sysinternals licence | Not for third-party redistribution; keep for your own use |
| YARA (VirusTotal) - bundled | BSD-3-Clause | Allowed |

No cracked, patched or unlicensed software is included or supported. Needing your approval before sharing the USB: KAPE, FTK Imager, Sysinternals tools, Volatility 3.
